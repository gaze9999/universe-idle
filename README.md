# Universe Idle

一款以宇宙探索為方向的純文字 Idle / Incremental 遊戲, 支援繁體中文與英文

[開始遊戲](https://gaze9999.github.io/universe-idle/)

從小型聚落開始, 派遣物種採集資源, 建造棲地與設施, 研究科技並發展文明, 透過傳承開啟新的成長路線

- 物種各有工作適性, 分歧與環境帶來不同的配置選擇
- 行星的日夜、季節與天氣影響生產
- 建造佇列可排序, 材料足夠後自動接續施工
- 離開時累積加速時間, 返回後自動加速

可在桌面與手機瀏覽器遊玩, 存檔保存在目前瀏覽器, 支援匯出與匯入備份
